# Стратегия Chart Patterns V2 - Классические ценовые паттерны

## Описание

Стратегия `chart_patterns_v2` реализует распознавание классических ценовых паттернов для технического анализа финансовых рынков. Это улучшенная версия v2 с поддержкой предсказания будущих сигналов.

## Поддерживаемые паттерны

### 1. Разворотные паттерны

#### Голова и плечи (Head and Shoulders)
- **Тип**: Медвежий разворот
- **Структура**: Три пика - левое плечо, голова (выше плеч), правое плечо
- **Сигнал**: SELL при пробое линии шеи (neckline)

#### Перевернутая голова и плечи (Inverse Head and Shoulders)
- **Тип**: Бычий разворот
- **Структура**: Три впадины - левое плечо, голова (ниже плеч), правое плечо
- **Сигнал**: BUY при пробое линии шеи

#### Двойная вершина (Double Top)
- **Тип**: Медвежий разворот
- **Структура**: Два пика на одном уровне с впадиной между ними
- **Сигнал**: SELL при пробое уровня поддержки

#### Двойное дно (Double Bottom)
- **Тип**: Бычий разворот
- **Структура**: Две впадины на одном уровне с пиком между ними
- **Сигнал**: BUY при пробое уровня сопротивления

#### Тройная вершина (Triple Top)
- **Тип**: Медвежий разворот
- **Структура**: Три пика на одном уровне
- **Сигнал**: SELL при пробое уровня поддержки

#### Тройное дно (Triple Bottom)
- **Тип**: Бычий разворот
- **Структура**: Три впадины на одном уровне
- **Сигнал**: BUY при пробое уровня сопротивления

### 2. Паттерны продолжения тренда

#### Бычий флаг (Bull Flag)
- **Тип**: Продолжение восходящего тренда
- **Структура**: Сильное восходящее движение (флагшток) + параллельная консолидация вниз (флаг)
- **Сигнал**: BUY при пробое верхней границы флага

#### Медвежий флаг (Bear Flag)
- **Тип**: Продолжение нисходящего тренда
- **Структура**: Сильное нисходящее движение (флагшток) + параллельная консолидация вверх (флаг)
- **Сигнал**: SELL при пробое нижней границы флага

#### Бычий вымпел (Bull Pennant)
- **Тип**: Продолжение восходящего тренда
- **Структура**: Сильное восходящее движение + сходящаяся консолидация
- **Сигнал**: BUY при пробое

#### Медвежий вымпел (Bear Pennant)
- **Тип**: Продолжение нисходящего тренда
- **Структура**: Сильное нисходящее движение + сходящаяся консолидация
- **Сигнал**: SELL при пробое

### 3. Треугольники (зоны консолидации)

#### Восходящий треугольник (Ascending Triangle)
- **Тип**: Обычно бычий пробой
- **Структура**: Горизонтальное сопротивление + восходящая поддержка
- **Сигнал**: BUY при пробое сопротивления

#### Нисходящий треугольник (Descending Triangle)
- **Тип**: Обычно медвежий пробой
- **Структура**: Горизонтальная поддержка + нисходящее сопротивление
- **Сигнал**: SELL при пробое поддержки

#### Симметричный треугольник (Symmetrical Triangle)
- **Тип**: Направление неопределенно
- **Структура**: Сходящиеся линии поддержки и сопротивления
- **Сигнал**: Зависит от направления предшествующего тренда

### 4. Клинья (Wedges)

#### Восходящий клин (Rising Wedge)
- **Тип**: Медвежий разворот
- **Структура**: Обе линии восходящие, но сходятся вверх
- **Сигнал**: SELL при пробое вниз

#### Нисходящий клин (Falling Wedge)
- **Тип**: Бычий разворот
- **Структура**: Обе линии нисходящие, но сходятся вниз
- **Сигнал**: BUY при пробое вверх

## Параметры конфигурации

```go
type ChartPatternsConfig struct {
    MinPatternLength      int     // Минимальная длина паттерна в свечах (по умолчанию: 8)
    MaxPatternLength      int     // Максимальная длина паттерна в свечах (по умолчанию: 30)
    ConfirmationThreshold float64 // Порог уверенности для подтверждения паттерна 0-1 (по умолчанию: 0.5)
    LookbackPeriod        int     // Период анализа для поиска паттернов (по умолчанию: 100)
    PriceTolerance        float64 // Допустимое отклонение цены в % (по умолчанию: 0.03 = 3%)
}
```

### Описание параметров

- **MinPatternLength**: Минимальное количество свечей для формирования паттерна. Меньшие значения позволяют находить более короткие паттерны, но могут давать ложные сигналы.

- **MaxPatternLength**: Максимальное количество свечей для паттерна. Большие значения позволяют находить долгосрочные паттерны.

- **ConfirmationThreshold**: Минимальная уверенность (0-1) для подтверждения паттерна. Более высокие значения дают меньше, но более надежных сигналов.

- **LookbackPeriod**: Количество свечей для анализа при поиске паттернов. Влияет на производительность.

- **PriceTolerance**: Допустимое отклонение цены при сравнении уровней (например, для определения, находятся ли два пика на одном уровне).

## Предсказание следующего сигнала (PredictNextSignal)

Стратегия поддерживает предсказание ближайшего сигнала в будущем на основе формирующихся паттернов:

```go
type FutureSignal struct {
    SignalType SignalType // BUY, SELL или HOLD
    Date       int64      // Unix timestamp предполагаемой даты сигнала
    Price      float64    // Ожидаемая цена пробоя
    Confidence float64    // Уверенность в предсказании (0-1)
}
```

### Логика предсказания

1. **Анализ формирующихся паттернов**: Стратегия ищет паттерны, которые еще не завершены, но близки к завершению.

2. **Оценка времени до пробоя**: Для каждого типа паттерна используется своя эвристика:
   - H&S: пробой через 1/4 длины паттерна
   - Двойные/тройные паттерны: через 1/3 длины
   - Треугольники: через 1/5 длины (ближе к вершине)
   - Клинья: через 1/4 длины
   - Флаги/вымпелы: через 1/6 длины (быстрый пробой)

3. **Корректировка уверенности**: Уверенность в предсказании снижается в зависимости от типа паттерна:
   - H&S, тройные паттерны: 85% от базовой уверенности
   - Двойные паттерны, флаги: 80%
   - Симметричные треугольники: 60% (направление неопределенно)

4. **Определение направления**: Для симметричных треугольников направление определяется по предшествующему тренду.

## Использование

### Запуск стратегии

```bash
# Тестирование только chart_patterns_v2
./backtester -file tmos_big.json -strategy chart_patterns_v2

# Тестирование всех стратегий (включая chart_patterns_v2)
./backtester -file tmos_big.json -strategy all
```

### Использование в коде

```go
// Создание стратегии
strategy := patterns.NewChartPatternsStrategyV2(0.01) // slippage = 0.01

// Получение конфигурации по умолчанию
config := strategy.DefaultConfig()

// Генерация сигналов
signals := strategy.GenerateSignals(candles, config)

// Предсказание следующего сигнала
futureSignal := strategy.(*internal.StrategyBase).PredictNextSignal(candles, config)
if futureSignal != nil {
    fmt.Printf("Следующий сигнал: %v на %v с уверенностью %.1f%%\n",
        futureSignal.SignalType,
        time.Unix(futureSignal.Date, 0),
        futureSignal.Confidence*100)
}

// Оптимизация параметров
optimizedConfig := strategy.Optimize(candles, strategy)

// Бэктестинг
result := internal.Backtest(candles, signals, 0.01)
```

## Преимущества и недостатки

### Преимущества

✅ Распознает широкий спектр классических паттернов  
✅ Поддерживает предсказание будущих сигналов  
✅ Автоматическая оптимизация параметров  
✅ Высокая уверенность в предсказаниях (84.9%)  
✅ Умеренное количество сделок (40 на 23,000 свечей)  
✅ Положительная доходность (+4.42%)  

### Недостатки

⚠️ Относительно медленная (35s на 23,000 свечей)  
⚠️ Требует достаточно данных для формирования паттернов  
⚠️ Может пропускать паттерны в периоды низкой волатильности  
⚠️ Субъективность в определении некоторых паттернов  

## Рекомендации по использованию

1. **Таймфрейм**: Лучше всего работает на средних и долгосрочных таймфреймах (4H, 1D)

2. **Комбинирование**: Рекомендуется использовать вместе с другими индикаторами для подтверждения сигналов

3. **Волатильность**: Наиболее эффективна на рынках с умеренной волатильностью

4. **Оптимизация**: Регулярно переоптимизируйте параметры под текущие рыночные условия

5. **Риск-менеджмент**: Используйте стоп-лоссы на уровнях, противоположных паттерну

## Алгоритм работы

1. **Поиск экстремумов**: Находит все локальные максимумы и минимумы
2. **Распознавание паттернов**: Применяет алгоритмы для каждого типа паттерна
3. **Оценка уверенности**: Вычисляет уверенность на основе качества паттерна
4. **Фильтрация**: Отбирает паттерны с уверенностью выше порога
5. **Генерация сигналов**: Создает торговые сигналы при пробое ключевых уровней
6. **Предсказание**: Анализирует формирующиеся паттерны для предсказания будущих сигналов
