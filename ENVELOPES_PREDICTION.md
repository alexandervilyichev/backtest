# Предсказание пробоя полос Envelopes

## Описание

Добавлена возможность предсказывать ближайший пробой верхней или нижней полосы Envelopes для стратегии Envelopes V2.

## Реализация

### Метод PredictNextSignal

Метод анализирует текущее движение цены относительно полос Envelopes и предсказывает точку пробоя.

```go
func (sg *EnvelopesSignalGenerator) PredictNextSignal(
    candles []internal.Candle,
    config internal.StrategyConfigV2,
) *internal.FutureSignal
```

### Алгоритм

1. **Расчет полос Envelopes**
   - Вычисляет SMA за заданный период
   - Верхняя полоса = SMA × (1 + процент)
   - Нижняя полоса = SMA × (1 - процент)

2. **Анализ движения цены**
   - Вычисляет среднюю скорость изменения цены за последние N свечей
   - Вычисляет скорость изменения средней линии (тренд)
   - Определяет расстояние до верхней и нижней полос

3. **Определение направления**
   - Если цена движется вверх → ожидается пробой верхней полосы (BUY)
   - Если цена движется вниз → ожидается пробой нижней полосы (SELL)
   - Если движения нет → предсказание невозможно

4. **Предсказание пробоя**
   - Вычисляет количество свечей до пробоя: `расстояние / скорость`
   - Экстраполирует цену и полосы в будущее
   - Определяет точную цену пробоя с учетом движения полос

5. **Оценка уверенности**
   - Базовая уверенность: 50%
   - **Сила движения** (+20% при velocityStrength > 1%)
   - **Близость к цели** (+20% при расстоянии < 1%)
   - **Согласованность** (+10% если цена и средняя движутся в одном направлении)
   - **Горизонт** (-20% при дальнем предсказании)
   - **Отклонение от средней** (+10% при сильном отклонении)

## Когда предсказание невозможно

Метод возвращает `nil` в следующих случаях:

1. **Недостаточно данных**
   - Меньше чем `Period * 2` свечей

2. **Нет направленного движения**
   - Скорость изменения цены близка к нулю
   - `|priceVelocity| < 0.0001`

3. **Низкая уверенность**
   - Расчетная уверенность < 30%
   - Слишком слабое движение или слишком далекий горизонт

## Использование

### Пример кода

```go
generator := volatility.NewEnvelopesSignalGenerator()

config := &volatility.EnvelopesConfig{
    Period:     20,
    Percentage: 0.02,
}

futureSignal := generator.PredictNextSignal(candles, config)

if futureSignal != nil {
    fmt.Printf("Тип: %s\n", futureSignal.SignalType)
    fmt.Printf("Дата: %s\n", time.Unix(futureSignal.Date, 0))
    fmt.Printf("Цена: %.4f\n", futureSignal.Price)
    fmt.Printf("Уверенность: %.2f%%\n", futureSignal.Confidence*100)
}
```

### Готовый пример


## Параметры конфигурации

### Популярные комбинации параметров

| Period | Percentage | Применение |
|--------|------------|------------|
| 10     | 2.5%       | Краткосрочная торговля, узкие полосы |
| 20     | 2.0%       | Среднесрочная торговля (стандарт) |
| 40     | 1.5%       | Долгосрочная торговля, широкие полосы |

### Выбор параметров

- **Короткий период (10-15)** - больше сигналов, но больше ложных пробоев
- **Средний период (20-30)** - баланс между частотой и надежностью
- **Длинный период (40-50)** - редкие, но надежные сигналы

- **Малый процент (1.5-2%)** - узкие полосы, частые пробои
- **Средний процент (2-3%)** - стандартная ширина
- **Большой процент (3-4%)** - широкие полосы, редкие пробои

## Интерпретация результатов

### Уверенность

- **>= 70%** - Высокая уверенность, надежный сигнал
- **50-70%** - Средняя уверенность, рекомендуется подтверждение
- **30-50%** - Низкая уверенность, используйте с осторожностью

### Типы сигналов

**Пробой верхней полосы (BUY)**
- Цена пробивает верхнюю полосу вверх
- Бычий сигнал
- Указывает на сильное восходящее движение (breakout)

**Пробой нижней полосы (SELL)**
- Цена пробивает нижнюю полосу вниз
- Медвежий сигнал
- Указывает на сильное нисходящее движение (breakdown)

## Ограничения

1. **Линейная экстраполяция**
   - Предполагает, что скорость движения цены останется постоянной
   - Не учитывает возможные развороты тренда

2. **Не учитывает внешние факторы**
   - Новости, события, фундаментальные изменения
   - Резкие изменения волатильности

3. **Работает лучше на трендовых рынках**
   - На боковых рынках может давать ложные сигналы пробоя
   - Требует подтверждения другими индикаторами

4. **Фиксированная ширина полос**
   - Не адаптируется к изменениям волатильности
   - В отличие от Bollinger Bands, не учитывает стандартное отклонение

## Рекомендации

1. **Используйте подтверждение**
   - Объем торгов (увеличение при пробое)
   - Другие индикаторы (RSI, MACD)
   - Уровни поддержки/сопротивления

2. **Учитывайте таймфрейм**
   - Долгосрочные периоды (40+) - для позиционной торговли
   - Краткосрочные периоды (10-20) - для активной торговли

3. **Проверяйте уверенность**
   - Не торгуйте по сигналам с низкой уверенностью (< 50%)
   - Ждите подтверждения при средней уверенности (50-70%)

4. **Следите за контекстом рынка**
   - На трендовых рынках пробои более надежны
   - На боковых рынках используйте с осторожностью

5. **Комбинируйте с другими стратегиями**
   - Bollinger Bands для учета волатильности
   - Moving Average для определения тренда
   - Volume для подтверждения пробоя
