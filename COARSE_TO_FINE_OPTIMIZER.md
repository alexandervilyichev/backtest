# Coarse-to-Fine Optimizer - Двухэтапная оптимизация параметров

## Описание

Двухэтапный оптимизатор параметров стратегий, использующий подход "от грубого к точному" (coarse-to-fine). Сначала выполняется быстрый поиск на грубой сетке для определения области оптимума, затем детальный поиск в этой области с мелким шагом.

## Преимущества

### По сравнению с обычным Grid Search

| Характеристика | Grid Search | Coarse-to-Fine |
|----------------|-------------|----------------|
| Количество тестов | N × M (все комбинации) | N + K × M (грубая + мелкая) |
| Время выполнения | Долго | Быстрее в 5-10 раз |
| Качество результата | Зависит от шага сетки | Лучше (адаптивный шаг) |
| Риск пропустить оптимум | Высокий при большом шаге | Низкий |

### Пример
- **Grid Search**: 10,000 конфигураций = 10,000 тестов
- **Coarse-to-Fine**: 100 грубых + 3 × 300 мелких = 1,000 тестов (в 10 раз быстрее!)

## Как работает

### Этап 1: Грубая сетка (Coarse Grid)
1. Генерируется небольшое количество конфигураций с большим шагом
2. Все конфигурации тестируются параллельно
3. Выбираются топ-N лучших конфигураций (по умолчанию N=3)

**Пример грубой сетки для Elliott Wave Advanced**:
```
MinWaveLength: [5, 10]           (шаг 5)
MaxWaveLength: [40, 60]          (шаг 20)
MinWaveAmplitude: [0.01, 0.02]   (шаг 0.01)
ConfidenceThreshold: [0.3, 0.5]  (шаг 0.2)
Features: [all_on, all_off]      (2 варианта)

Итого: 2 × 2 × 2 × 2 × 2 = 32 конфигурации
```

### Этап 2: Мелкая сетка (Fine Grid)
1. Вокруг каждой из топ-N конфигураций генерируется мелкая сетка
2. Параметры варьируются в диапазоне ±10-20% с малым шагом
3. Все конфигурации мелкой сетки тестируются параллельно
4. Выбирается лучшая конфигурация из всех

**Пример мелкой сетки вокруг оптимума**:
```
Если лучшая конфигурация: MinWaveLength=10

Мелкая сетка:
MinWaveLength: [8, 10, 12]       (шаг 2, ±20%)
MaxWaveLength: [50, 60, 70]      (шаг 10, ±17%)
MinWaveAmplitude: [0.015, 0.02, 0.025]  (шаг 0.005, ±25%)
ConfidenceThreshold: [0.2, 0.3, 0.4]    (шаг 0.1, ±33%)
Features: [8 комбинаций]         (все варианты)

Итого: 3 × 3 × 3 × 3 × 8 = 648 конфигураций на каждый оптимум
```

## Реализация

### CoarseToFineOptimizer

Базовый двухэтапный оптимизатор.

```go
optimizer := internal.NewCoarseToFineOptimizer(
    slippageProvider,
    configGenerator.GenerateCoarse,  // функция грубой сетки
    configGenerator.GenerateFine,    // функция мелкой сетки
    3,                               // топ-3 для уточнения
)
```

**Параметры**:
- `slippageProvider`: провайдер проскальзывания
- `coarseConfigGenerator`: функция генерации грубой сетки
- `fineConfigGenerator`: функция генерации мелкой сетки (принимает лучшую конфигурацию)
- `topN`: количество лучших конфигураций для уточнения

### AdaptiveCoarseToFineOptimizer

Адаптивный оптимизатор с итеративным уточнением.

```go
optimizer := internal.NewAdaptiveCoarseToFineOptimizer(
    slippageProvider,
    configGenerator.GenerateCoarse,
    configGenerator.GenerateFine,
    3,      // топ-3
    0.01,   // порог улучшения 1%
)
```

**Дополнительные возможности**:
- Итеративное уточнение (до 3 итераций)
- Автоматическая остановка при незначительном улучшении
- Адаптивное сужение области поиска

## Как использовать

### 1. Создайте генератор конфигураций

```go
type MyConfigGenerator struct{}

// Грубая сетка - широкий диапазон, большой шаг
func (g *MyConfigGenerator) GenerateCoarse() []internal.StrategyConfigV2 {
    configs := make([]internal.StrategyConfigV2, 0)
    
    // Параметры с большим шагом
    param1Values := []int{10, 50, 100}      // шаг 40-50
    param2Values := []float64{0.1, 0.5}     // шаг 0.4
    
    for _, p1 := range param1Values {
        for _, p2 := range param2Values {
            configs = append(configs, &MyConfig{
                Param1: p1,
                Param2: p2,
            })
        }
    }
    
    return configs
}

// Мелкая сетка - узкий диапазон вокруг оптимума, малый шаг
func (g *MyConfigGenerator) GenerateFine(best internal.StrategyConfigV2) []internal.StrategyConfigV2 {
    bestConfig := best.(*MyConfig)
    configs := make([]internal.StrategyConfigV2, 0)
    
    // Параметры с малым шагом вокруг оптимума (±20%)
    param1Values := []int{
        bestConfig.Param1 - 10,
        bestConfig.Param1,
        bestConfig.Param1 + 10,
    }
    
    param2Values := []float64{
        bestConfig.Param2 - 0.05,
        bestConfig.Param2,
        bestConfig.Param2 + 0.05,
    }
    
    for _, p1 := range param1Values {
        for _, p2 := range param2Values {
            configs = append(configs, &MyConfig{
                Param1: p1,
                Param2: p2,
            })
        }
    }
    
    return configs
}
```

### 2. Создайте оптимизатор

```go
configGenerator := NewMyConfigGenerator()

optimizer := internal.NewCoarseToFineOptimizer(
    slippageProvider,
    configGenerator.GenerateCoarse,
    configGenerator.GenerateFine,
    3, // топ-3 конфигурации
)
```

### 3. Используйте в стратегии

```go
strategy := internal.NewStrategyBase(
    "my_strategy",
    signalGenerator,
    configManager,
    optimizer,  // используем двухэтапный оптимизатор
    slippageProvider,
)
```

## Рекомендации

### Размер грубой сетки
- **Маленькие датасеты** (< 1,000 свечей): 20-50 конфигураций
- **Средние датасеты** (1,000-10,000): 30-100 конфигураций
- **Большие датасеты** (> 10,000): 50-200 конфигураций

### Размер мелкой сетки
- **Простые стратегии** (2-3 параметра): 50-200 конфигураций на оптимум
- **Средние стратегии** (4-6 параметров): 200-500 конфигураций
- **Сложные стратегии** (7+ параметров): 500-1,000 конфигураций

### Количество топ-N
- **topN = 1**: быстро, но риск локального оптимума
- **topN = 3**: оптимальный баланс (рекомендуется)
- **topN = 5**: медленнее, но надежнее

### Диапазон мелкой сетки
- **Консервативный**: ±10% от оптимума
- **Сбалансированный**: ±20% (рекомендуется)
- **Агрессивный**: ±30-50%

## Ограничения

1. **Дискретные параметры**: работает лучше всего с дискретными параметрами
2. **Локальные оптимумы**: может застрять в локальном оптимуме (используйте topN > 1)
3. **Вычислительные ресурсы**: требует параллельных вычислений
4. **Зависимость параметров**: не учитывает взаимозависимость параметров

## Дальнейшее развитие

### Возможные улучшения
1. **Байесовская оптимизация**: использовать Gaussian Process для предсказания оптимума
2. **Генетические алгоритмы**: эволюционный поиск оптимальных параметров
3. **Gradient-based методы**: для непрерывных параметров
4. **Multi-objective optimization**: оптимизация по нескольким метрикам одновременно
5. **Adaptive grid**: автоматическое определение размера и шага сетки

## Заключение

Двухэтапная оптимизация "coarse-to-fine" - это эффективный подход для поиска оптимальных параметров стратегий. Он сочетает скорость грубого поиска с точностью детального уточнения, обеспечивая лучшие результаты за меньшее время.

**Ключевые преимущества**:
- ⚡ Быстрее в 5-10 раз
- 🎯 Лучшее качество результатов
- 🔍 Меньше риск пропустить оптимум
- 🛠️ Легко адаптируется под любую стратегию
