# QStick Oscillator Strategy V2 - Предсказание сигналов

## Описание стратегии

QStick Oscillator — это индикатор импульса, который определяет тренд актива путем расчета простого скользящего среднего (SMA) разницы между ценой закрытия и открытия. QStick показывает давление покупателей и продавцов на основе внутридневных изменений цены.

### Формула

```
QStick(t) = SMA(Close - Open, period)
```

где:
- `Close` — цена закрытия свечи
- `Open` — цена открытия свечи
- `period` — период расчета SMA (обычно 8-21)

### Интерпретация

- **QStick > 0** — преобладает давление покупателей (цены закрытия выше цен открытия)
- **QStick < 0** — преобладает давление продавцов (цены закрытия ниже цен открытия)
- **QStick ≈ 0** — баланс между покупателями и продавцами

## Торговые правила

### Сигнал на покупку (BUY)
- QStick поднимается **выше** порога покупки (buyThreshold)
- Подтверждается **положительным трендом** (линейная регрессия)
- Цена **растет**
- QStick **растет** (импульс усиливается)
- Волатильность **выше минимального порога**

### Сигнал на продажу (SELL)
- QStick опускается **ниже** порога продажи (sellThreshold)
- Подтверждается **отрицательным трендом**
- Цена **падает**
- QStick **падает** (импульс ослабевает)

### Управление рисками
- **Stop-Loss:** автоматический выход при достижении уровня убытка
- **Take-Profit:** автоматический выход при достижении целевой прибыли
- **Trailing Stop:** стоп-лосс подтягивается за ценой при росте

## Параметры стратегии

| Параметр | Описание | Значение по умолчанию | Диапазон оптимизации |
|----------|----------|----------------------|---------------------|
| `period` | Период для расчета SMA | 12 | 12-19 (шаг 1) |
| `buy_threshold` | Порог для покупки | -1.5 | -2.0 до -1.0 (шаг 0.2) |
| `sell_threshold` | Порог для продажи | 0.2 | 0.2-1.0 (шаг 0.2) |
| `stop_loss_percent` | Процент стоп-лосса | 1.0% | 1-3% (шаг 1%) |
| `take_profit_percent` | Процент тейк-профита | 6.0% | 4-9% (шаг 1%) |
| `volatility_filter` | Минимальная волатильность | 0.0045 | 0.003-0.005 (шаг 0.0003) |

## Алгоритм предсказания

Метод `PredictNextSignal` анализирует текущее состояние индикатора и предсказывает следующий торговый сигнал.

### Этапы предсказания

1. **Расчет текущих значений**
   - Вычисляется QStick для всех свечей
   - Определяется направление тренда (линейная регрессия)
   - Анализируется текущее положение QStick

2. **Анализ скорости изменения**
   - Вычисляется средняя скорость изменения QStick за последние N свечей
   - Определяется направление движения индикатора

3. **Определение целевого уровня**
   - Если QStick < buyThreshold и растет → ожидается BUY
   - Если QStick > sellThreshold и падает → ожидается SELL
   - В нейтральной зоне учитывается направление тренда

4. **Расчет времени до сигнала**
   ```
   candlesToTarget = distanceToTarget / qstickVelocity
   ```

5. **Экстраполяция цены**
   - Вычисляется средняя скорость изменения цены
   - Прогнозируется цена в момент сигнала

6. **Оценка уверенности**
   - Анализируется множество факторов (см. ниже)

### Факторы уверенности

Уверенность в предсказании (confidence) рассчитывается на основе следующих факторов:

| Фактор | Влияние | Описание |
|--------|---------|----------|
| **Сила движения QStick** | +0.10 до +0.20 | Чем быстрее изменяется QStick, тем выше уверенность |
| **Близость к целевому уровню** | +0.10 до +0.20 | Чем ближе к порогу, тем скорее произойдет сигнал |
| **Согласованность с трендом** | -0.10 до +0.20 | QStick и тренд движутся в одном направлении |
| **Стабильность скорости** | +0.10 до +0.15 | Постоянство скорости изменения на предыдущих периодах |
| **Горизонт предсказания** | -0.20 до +0.10 | Близкие предсказания надежнее дальних |
| **Согласованность с ценой** | -0.05 до +0.10 | Движение QStick в том же направлении, что и цена |

**Минимальный порог уверенности:** 0.30 (30%)

### Условия отказа от предсказания

Предсказание не выполняется, если:
- Недостаточно исторических данных (< period × 3 свечей)
- QStick движется в направлении от целевого уровня
- Слишком слабое движение индикатора
- Нет согласованности между QStick и трендом
- Уверенность ниже минимального порога (< 30%)

## Интерпретация результатов

### Высокая уверенность (> 60%)
- Сильное направленное движение QStick
- Согласованность с трендом
- Близость к целевому уровню
- Стабильная скорость изменения

**Рекомендация:** Можно рассматривать для торговли

### Средняя уверенность (40-60%)
- Умеренное движение индикатора
- Частичная согласованность с трендом
- Средний горизонт предсказания

**Рекомендация:** Требуется дополнительное подтверждение

### Низкая уверенность (30-40%)
- Слабое движение QStick
- Дивергенция с трендом или ценой
- Дальний горизонт предсказания

**Рекомендация:** Высокий риск, лучше дождаться более четкого сигнала

## Преимущества и ограничения

### Преимущества
✅ Простота расчета и понимания  
✅ Показывает реальное давление покупателей/продавцов  
✅ Работает на разных таймфреймах  
✅ Хорошо фильтрует рыночный шум через SMA  
✅ Встроенное управление рисками (SL/TP)  
✅ Фильтрация по волатильности  

### Ограничения
⚠️ Может запаздывать в быстрых движениях рынка  
⚠️ Зависит от правильного выбора периода  
⚠️ Не учитывает объем торгов  
⚠️ Требует подтверждения трендом  

## Рекомендации по использованию

1. **Комбинируйте с другими индикаторами**
   - Используйте объемные индикаторы для подтверждения
   - Добавьте индикаторы волатильности
   - Проверяйте на более длинных таймфреймах

2. **Оптимизируйте параметры**
   - Для волатильных активов: уменьшите period (8-10)
   - Для стабильных активов: увеличьте period (15-21)
   - Настройте пороги под конкретный актив

3. **Учитывайте рыночные условия**
   - В трендовом рынке: стратегия работает лучше
   - В боковом рынке: увеличьте фильтр волатильности
   - При высокой волатильности: расширьте стоп-лосс

4. **Управление рисками**
   - Всегда используйте стоп-лоссы
   - Не входите в позицию при низкой уверенности
   - Учитывайте горизонт предсказания
   - Следите за trailing stop

## Технические детали

### Минимальные требования к данным
- Минимум свечей: `period × 3`
- Рекомендуемое количество: `> 100 свечей`

### Производительность
- Сложность расчета: O(n × period)
- Использует кэширование для оптимизации
- Быстрая генерация сигналов

## Особенности реализации

### Фильтры ложных сигналов
- Проверка направления тренда перед входом
- Подтверждение движением цены
- Подтверждение ростом/падением QStick
- Фильтрация по минимальной волатильности

### Trailing Stop
Стоп-лосс автоматически подтягивается за ценой:
```go
if currentPrice > entryPrice {
    trailingStopLoss = currentPrice × (1 - stopLossPercent/100)
    if trailingStopLoss > stopLossPrice {
        stopLossPrice = trailingStopLoss
    }
}
```

### Определение тренда
Используется линейная регрессия для определения направления:
- Положительный наклон → восходящий тренд
- Отрицательный наклон → нисходящий тренд
- Период тренда = period × 2
