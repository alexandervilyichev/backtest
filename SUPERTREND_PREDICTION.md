# SuperTrend Strategy V2 - Предсказание сигналов

## Обзор

Стратегия SuperTrend V2 расширена методом `PredictNextSignal`, который предсказывает ближайший момент пересечения цены с линией SuperTrend.

## Как работает предсказание

### Основная идея

SuperTrend - это динамический индикатор тренда, который адаптируется к волатильности рынка через ATR (Average True Range). Линия SuperTrend следует за ценой:
- **Восходящий тренд**: линия находится ниже цены (зеленая)
- **Нисходящий тренд**: линия находится выше цены (красная)

Сигналы генерируются при пересечении:
- **BUY**: цена пересекает линию снизу вверх (переход в восходящий тренд)
- **SELL**: цена пересекает линию сверху вниз (переход в нисходящий тренд)

### Алгоритм предсказания

1. **Анализ текущего состояния**
   - Определяем текущий тренд (восходящий/нисходящий)
   - Вычисляем расстояние между ценой и линией SuperTrend
   - Рассчитываем текущий ATR (волатильность)

2. **Вычисление скоростей**
   - Скорость изменения цены (priceVelocity)
   - Скорость изменения линии SuperTrend (supertrendVelocity)
   - Скорость изменения ATR (atrVelocity)
   - Относительная скорость сближения (relativeVelocity = priceVelocity - supertrendVelocity)

3. **Проверка возможности пересечения**
   - Если восходящий тренд и цена растет быстрее SuperTrend → расхождение, предсказание невозможно
   - Если нисходящий тренд и цена падает быстрее SuperTrend → расхождение, предсказание невозможно
   - Только при сближении линий возможно предсказание

4. **Расчет времени до пересечения**
   ```
   candlesToCrossing = |distanceToSuperTrend / relativeVelocity|
   ```

5. **Экстраполяция в будущее**
   - Прогнозируем положение цены
   - Прогнозируем положение линии SuperTrend
   - Прогнозируем значение ATR
   - Определяем точку пересечения

6. **Оценка уверенности**
   Уверенность вычисляется на основе нескольких факторов:
   - **Сила движения** (20%): чем быстрее относительное движение, тем выше уверенность
   - **Близость к линии** (20%): чем ближе цена к SuperTrend, тем надежнее предсказание
   - **Стабильность волатильности** (10%): стабильный ATR повышает уверенность
   - **Горизонт предсказания** (10%): близкие события предсказываются точнее
   - **Соотношение расстояния к ATR** (15%): если расстояние < ATR, пересечение более вероятно

## Параметры конфигурации

```go
type SupertrendConfig struct {
    Period     int     // Период расчета ATR (обычно 10-14)
    Multiplier float64 // Множитель для ATR (обычно 2.0-3.0)
}
```

### Рекомендуемые значения

- **Краткосрочная торговля**: Period=7, Multiplier=2.0
- **Среднесрочная торговля**: Period=10, Multiplier=3.0 (по умолчанию)
- **Долгосрочная торговля**: Period=14, Multiplier=3.5

## Структура предсказания

```go
type FutureSignal struct {
    SignalType SignalType // BUY, SELL или HOLD
    Date       int64      // Unix timestamp ожидаемого сигнала
    Price      float64    // Ожидаемая цена в момент сигнала
    Confidence float64    // Уверенность в предсказании (0.0 - 1.0)
}
```

## Интерпретация уверенности

- **≥ 0.70**: Высокая уверенность - сигнал очень вероятен
- **0.50 - 0.69**: Средняя уверенность - сигнал вероятен, но требует подтверждения
- **0.30 - 0.49**: Низкая уверенность - сигнал возможен, но ненадежен
- **< 0.30**: Предсказание не возвращается (слишком низкая уверенность)

## Примеры использования

### Базовый пример

```go
package main

import (
    "bt/internal"
    "bt/strategies/v2/trend"
    "fmt"
)

func main() {
    // Загружаем данные
    candles := loadCandles("data.json")
    
    // Создаем генератор
    generator := trend.NewSupertrendSignalGenerator()
    
    // Конфигурация
    config := &trend.SupertrendConfig{
        Period:     10,
        Multiplier: 3.0,
    }
    
    // Предсказываем сигнал
    signal := generator.PredictNextSignal(candles, config)
    
    if signal != nil {
        fmt.Printf("Тип: %v\n", signal.SignalType)
        fmt.Printf("Дата: %v\n", time.Unix(signal.Date, 0))
        fmt.Printf("Цена: %.4f\n", signal.Price)
        fmt.Printf("Уверенность: %.1f%%\n", signal.Confidence*100)
    }
}
```

### Использование через V2 API

```go
// Получаем стратегию из реестра
strategy, _ := internal.GetStrategyV2("supertrend_v2")

// Оптимизируем параметры
config := strategy.Optimize(candles, strategy)

// Генерируем сигналы
signals := strategy.GenerateSignals(candles, config)

// Предсказываем следующий сигнал
if strategyBase, ok := strategy.(*internal.StrategyBase); ok {
    futureSignal := strategyBase.PredictNextSignal(candles, config)
    // Обрабатываем предсказание
}
```

## Когда предсказание невозможно

Метод `PredictNextSignal` возвращает `nil` в следующих случаях:

1. **Недостаточно данных**: меньше чем `Period * 2` свечей
2. **Расхождение линий**: цена и SuperTrend движутся в разные стороны
3. **Слабое движение**: относительная скорость слишком мала (< 0.0001)
4. **Далекий горизонт**: пересечение ожидается позже чем через `Period * 2` свечей
5. **Низкая уверенность**: расчетная уверенность < 0.30

## Ограничения и предостережения

### Технические ограничения

1. **Линейная экстраполяция**: предсказание основано на линейной экстраполяции, что может быть неточно при резких изменениях рынка
2. **Зависимость от волатильности**: в периоды высокой волатильности точность снижается
3. **Горизонт предсказания**: чем дальше в будущее, тем менее надежно предсказание

### Рыночные условия

- **Лучше работает**: в трендовых рынках с умеренной волатильностью
- **Хуже работает**: в боковых рынках, при резких новостных движениях
- **Не подходит**: для скальпинга, высокочастотной торговли

### Рекомендации по использованию

1. **Не полагайтесь только на предсказание**: используйте его как дополнительный сигнал
2. **Учитывайте уверенность**: игнорируйте предсказания с низкой уверенностью
3. **Комбинируйте с другими индикаторами**: используйте подтверждение от других стратегий
4. **Мониторьте изменения**: предсказание может меняться с приходом новых данных
5. **Используйте стоп-лоссы**: всегда защищайте позиции

## Сравнение с другими стратегиями

| Стратегия | Тип индикатора | Сложность предсказания | Точность |
|-----------|----------------|------------------------|----------|
| Golden Cross | Пересечение MA | Средняя | Высокая |
| Envelopes | Полосы волатильности | Средняя | Средняя |
| **SuperTrend** | **Тренд + волатильность** | **Высокая** | **Высокая** |

SuperTrend сочетает преимущества трендовых индикаторов и индикаторов волатильности, что делает предсказания более надежными в различных рыночных условиях.
