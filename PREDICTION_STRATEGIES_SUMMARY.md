# Сводка по стратегиям с предсказанием сигналов

## Обзор

В систему добавлены методы предсказания следующего сигнала (`PredictNextSignal`) для следующих стратегий:

1. **Golden Cross** - пересечение скользящих средних
2. **Envelopes** - полосы волатильности
3. **SuperTrend** - трендовый индикатор с ATR
4. **Awesome Oscillator** - осциллятор рыночной энергии
5. **RSI Oscillator** - индекс относительной силы
6. **CCI Oscillator** - индекс товарного канала
7. **Elliott Wave** - волновой анализ
8. **Predictive Spline** - сплайн-интерполяция с предсказанием
9. **Predictive Linear Spline** - линейная сплайн-интерполяция

## Как работает предсказание

### Общий подход

Все стратегии используют схожий подход к предсказанию:

1. **Анализ текущего состояния** - определение положения индикатора
2. **Вычисление скорости изменения** - производная индикатора
3. **Экстраполяция в будущее** - линейная или нелинейная
4. **Расчет времени до сигнала** - количество свечей
5. **Оценка уверенности** - на основе множества факторов

### Факторы уверенности

Уверенность в предсказании вычисляется на основе:

- **Сила движения** (15-20%): скорость изменения индикатора
- **Близость к цели** (15-20%): расстояние до целевого уровня
- **Стабильность** (10-15%): постоянство скорости изменения
- **Горизонт** (10%): время до предсказанного события
- **Согласованность** (10%): соответствие движения индикатора и цены
- **Дополнительные факторы** (10-20%): специфичные для каждой стратегии

## Использование в коде

### Через V2 API

```go
// Получаем стратегию
strategy, _ := internal.GetStrategyV2("rsi_oscillator_v2")

// Оптимизируем параметры
config := strategy.Optimize(candles, strategy)

// Предсказываем следующий сигнал
if strategyBase, ok := strategy.(*internal.StrategyBase); ok {
    futureSignal := strategyBase.PredictNextSignal(candles, config)
    
    if futureSignal != nil {
        fmt.Printf("Тип: %v\n", futureSignal.SignalType)
        fmt.Printf("Дата: %v\n", time.Unix(futureSignal.Date, 0))
        fmt.Printf("Цена: %.4f\n", futureSignal.Price)
        fmt.Printf("Уверенность: %.1f%%\n", futureSignal.Confidence*100)
    }
}
```

### Напрямую через генератор

```go
// Создаем генератор
generator := oscillators.NewRSISignalGenerator()

// Конфигурация
config := &oscillators.RSIConfig{
    Period:        14,
    BuyThreshold:  30.0,
    SellThreshold: 70.0,
}

// Предсказываем
signal := generator.PredictNextSignal(candles, config)
```

## Рекомендации по выбору стратегии

### Для трендовых рынков

1. **Golden Cross** - надежное определение смены тренда
2. **SuperTrend** - адаптируется к волатильности
3. **Envelopes** - хорошо работает при пробоях

### Для боковых рынков

1. **RSI Oscillator** - классический выбор для осцилляций
2. **Awesome Oscillator** - определяет изменение энергии
3. **CCI Oscillator** - чувствителен к отклонениям

### Для волатильных рынков

1. **SuperTrend** - учитывает ATR
2. **Envelopes** - адаптивные полосы
3. **CCI Oscillator** - нормализует отклонения

### Для долгосрочной торговли

1. **Golden Cross** - медленные MA фильтруют шум
2. **Elliott Wave** - анализ крупных волн
3. **SuperTrend** - стабильные сигналы

## Ограничения

### Общие для всех стратегий

1. **Линейная экстраполяция**: не учитывает резкие изменения
2. **Запаздывание**: все индикаторы основаны на исторических данных
3. **Рыночные условия**: точность зависит от типа рынка
4. **Горизонт предсказания**: чем дальше, тем менее точно

### Когда предсказание невозможно

Предсказание возвращает `nil` если:

- Недостаточно исторических данных
- Индикатор движется от целевого уровня
- Слишком слабое движение индикатора
- Низкая уверенность (< 30%)
- Горизонт предсказания слишком далек

## Лучшие практики

### 1. Комбинируйте стратегии

Используйте предсказания нескольких стратегий для подтверждения:

```go
signals := []struct{
    name string
    signal *internal.FutureSignal
}{
    {"RSI", rsiGenerator.PredictNextSignal(candles, rsiConfig)},
    {"AO", aoGenerator.PredictNextSignal(candles, aoConfig)},
    {"SuperTrend", stGenerator.PredictNextSignal(candles, stConfig)},
}

// Если несколько стратегий предсказывают одинаковый сигнал - сильное подтверждение
```

### 2. Учитывайте уверенность

```go
if signal != nil && signal.Confidence >= 0.7 {
    // Высокая уверенность - можно действовать
} else if signal != nil && signal.Confidence >= 0.5 {
    // Средняя уверенность - требуется подтверждение
} else {
    // Низкая уверенность - игнорируем
}
```

### 3. Мониторьте изменения

Предсказание может меняться с приходом новых данных:

```go
// Обновляем предсказание на каждой новой свече
for newCandle := range candleStream {
    candles = append(candles, newCandle)
    signal = generator.PredictNextSignal(candles, config)
    
    if signal != nil {
        log.Printf("Обновленное предсказание: %v через %d свечей",
            signal.SignalType, candlesToSignal(signal, candles))
    }
}
```

### 4. Используйте стоп-лоссы

Предсказания не гарантируют результат - всегда защищайте позиции:

```go
if signal != nil && signal.SignalType == internal.BUY {
    // Входим в позицию
    entryPrice := currentPrice
    stopLoss := entryPrice * 0.98  // 2% стоп-лосс
    takeProfit := signal.Price      // Предсказанная цена
}
```

### Оптимизация

Предсказание выполняется только один раз после оптимизации параметров, поэтому не влияет на общее время выполнения.
