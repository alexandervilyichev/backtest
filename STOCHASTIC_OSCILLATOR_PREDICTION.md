# Stochastic Oscillator Strategy V2 - Предсказание сигналов

## Описание стратегии

Стохастический осциллятор (Stochastic Oscillator) — это индикатор импульса, который сравнивает текущую цену закрытия с диапазоном цен за определенный период времени. Индикатор состоит из двух линий:

- **%K** (быстрая линия) — показывает текущее положение цены относительно диапазона High-Low
- **%D** (медленная линия) — скользящее среднее от %K

### Формулы

```
%K = 100 × (Close - Lowest Low) / (Highest High - Lowest Low)
%D = SMA(%K, dPeriod)
```

где:
- `Close` — текущая цена закрытия
- `Lowest Low` — минимальная цена за период kPeriod
- `Highest High` — максимальная цена за период kPeriod
- `SMA` — простое скользящее среднее

## Торговые правила

### Сигнал на покупку (BUY)
- %K пересекает %D **снизу вверх**
- Пересечение происходит в зоне **перепроданности** (ниже порога buyThreshold, обычно 20)

### Сигнал на продажу (SELL)
- %K пересекает %D **сверху вниз**
- Пересечение происходит в зоне **перекупленности** (выше порога sellThreshold, обычно 80)

## Параметры стратегии

| Параметр | Описание | Значение по умолчанию | Диапазон оптимизации |
|----------|----------|----------------------|---------------------|
| `k_period` | Период для расчета %K | 14 | 10-20 (шаг 2) |
| `d_period` | Период для расчета %D (SMA от %K) | 3 | 3-8 (шаг 1) |
| `buy_threshold` | Порог перепроданности для покупки | 20.0 | 15-30 (шаг 5) |
| `sell_threshold` | Порог перекупленности для продажи | 80.0 | 70-85 (шаг 5) |

## Алгоритм предсказания

Метод `PredictNextSignal` анализирует текущее состояние индикатора и предсказывает следующий торговый сигнал.

### Этапы предсказания

1. **Расчет текущих значений**
   - Вычисляются %K и %D для всех свечей
   - Определяются текущие значения обеих линий

2. **Анализ скорости изменения**
   - Вычисляется средняя скорость изменения %K за последние N свечей (lookback)
   - Вычисляется средняя скорость изменения %D за последние N свечей
   - Определяется относительная скорость: `relativeVelocity = kVelocity - dVelocity`

3. **Определение направления движения**
   - Если %K ниже %D и движется вверх быстрее → ожидается пересечение снизу вверх (BUY)
   - Если %K выше %D и движется вниз быстрее → ожидается пересечение сверху вниз (SELL)

4. **Проверка зон**
   - Для BUY: %K должен быть в зоне перепроданности или близко к ней
   - Для SELL: %K должен быть в зоне перекупленности или близко к ней

5. **Расчет времени до сигнала**
   ```
   candlesToSignal = |distanceBetweenLines| / |relativeVelocity|
   ```

6. **Экстраполяция цены**
   - Вычисляется средняя скорость изменения цены
   - Прогнозируется цена в момент сигнала

7. **Оценка уверенности**
   - Анализируется множество факторов (см. ниже)

### Факторы уверенности

Уверенность в предсказании (confidence) рассчитывается на основе следующих факторов:

| Фактор | Влияние | Описание |
|--------|---------|----------|
| **Сила относительного движения** | +0.10 до +0.20 | Чем быстрее линии сближаются, тем выше уверенность |
| **Близость линий** | +0.10 до +0.20 | Чем ближе %K к %D, тем скорее произойдет пересечение |
| **Положение в правильной зоне** | +0.10 до +0.20 | Нахождение в зоне перепроданности/перекупленности |
| **Стабильность скорости** | +0.10 до +0.15 | Постоянство скорости изменения на предыдущих периодах |
| **Горизонт предсказания** | -0.20 до +0.10 | Близкие предсказания надежнее дальних |
| **Согласованность с ценой** | -0.05 до +0.10 | Движение %K в том же направлении, что и цена |
| **Экстремальные значения** | +0.10 до +0.15 | %K в крайних зонах (<10 или >90) |

**Минимальный порог уверенности:** 0.30 (30%)

### Условия отказа от предсказания

Предсказание не выполняется, если:
- Недостаточно исторических данных (< kPeriod + dPeriod + 10 свечей)
- Слишком слабое относительное движение линий (< 0.1)
- Линии движутся в неправильном направлении (расходятся вместо сближения)
- %K находится слишком далеко от целевой зоны
- Уверенность ниже минимального порога (< 30%)

## Интерпретация результатов

### Высокая уверенность (> 60%)
- Линии быстро сближаются
- Стабильное направленное движение
- Нахождение в правильной зоне
- Короткий горизонт предсказания

**Рекомендация:** Можно рассматривать для торговли

### Средняя уверенность (40-60%)
- Умеренная скорость сближения
- Некоторая нестабильность движения
- Средний горизонт предсказания

**Рекомендация:** Требуется дополнительное подтверждение

### Низкая уверенность (30-40%)
- Слабое движение линий
- Нестабильность или дивергенция
- Дальний горизонт предсказания

**Рекомендация:** Высокий риск, лучше дождаться более четкого сигнала

## Преимущества и ограничения

### Преимущества
✅ Четкие сигналы на основе пересечения линий  
✅ Фильтрация по зонам перекупленности/перепроданности  
✅ Хорошо работает в трендовых рынках  
✅ Учитывает импульс движения цены  

### Ограничения
⚠️ Может давать ложные сигналы в боковом тренде  
⚠️ Запаздывание из-за использования скользящих средних  
⚠️ Требует достаточного количества исторических данных  
⚠️ Чувствителен к выбору параметров  

## Рекомендации по использованию

1. **Комбинируйте с другими индикаторами**
   - Используйте трендовые индикаторы для подтверждения направления
   - Добавьте индикаторы объема для подтверждения силы движения

2. **Оптимизируйте параметры**
   - Для волатильных активов: уменьшите kPeriod (10-12)
   - Для стабильных активов: увеличьте kPeriod (16-20)
   - Настройте пороги под конкретный актив

3. **Учитывайте рыночные условия**
   - В трендовом рынке: стратегия работает лучше
   - В боковом рынке: увеличьте пороги уверенности

4. **Управление рисками**
   - Используйте стоп-лоссы
   - Не входите в позицию при низкой уверенности
   - Учитывайте горизонт предсказания

## Технические детали

### Минимальные требования к данным
- Минимум свечей: `kPeriod + dPeriod + 10`
- Рекомендуемое количество: `> 100 свечей`

### Производительность
- Сложность расчета: O(n × kPeriod)
- Использует кэширование для оптимизации
- Быстрая генерация сигналов
