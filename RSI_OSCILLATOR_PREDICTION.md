# RSI Oscillator Strategy V2 - Предсказание сигналов

## Обзор

Стратегия RSI Oscillator V2 расширена методом `PredictNextSignal`, который предсказывает ближайший момент достижения RSI пороговых уровней перекупленности/перепроданности.

## Как работает предсказание

### Основная идея

RSI (Relative Strength Index) — индикатор импульса, измеряющий скорость и изменение ценовых движений на шкале от 0 до 100. Разработан Дж. Уэллсом Уайлдером.

```
RSI = 100 - (100 / (1 + RS))
RS = Средний прирост / Средняя потеря за период
```

Сигналы генерируются при достижении пороговых уровней:
- **BUY**: RSI опускается ниже уровня перепроданности (обычно 30)
- **SELL**: RSI поднимается выше уровня перекупленности (обычно 70)

### Алгоритм предсказания

1. **Анализ текущего состояния**
   - Определяем текущее значение RSI
   - Определяем положение относительно пороговых уровней
   - Вычисляем расстояние до ближайшего порога

2. **Вычисление скорости изменения**
   - Скорость изменения RSI (rsiVelocity) - производная RSI
   - Скорость изменения цены (priceVelocity)
   - Анализируем последние 3-5 свечей для определения тренда

3. **Определение целевого уровня**
   - **RSI < BuyThreshold**: уже в зоне перепроданности, предсказываем SELL (достижение SellThreshold)
   - **RSI > SellThreshold**: уже в зоне перекупленности, предсказываем BUY (достижение BuyThreshold)
   - **BuyThreshold < RSI < SellThreshold**: нейтральная зона
     - Если RSI растет → предсказываем SELL (достижение SellThreshold)
     - Если RSI падает → предсказываем BUY (достижение BuyThreshold)

4. **Расчет времени до достижения уровня**
   ```
   candlesToTarget = |distanceToTarget / rsiVelocity|
   ```

5. **Экстраполяция в будущее**
   - Прогнозируем значение RSI в момент достижения порога
   - Прогнозируем цену в этот момент
   - Используем линейную экстраполяцию

6. **Оценка уверенности**
   Уверенность вычисляется на основе нескольких факторов:
   - **Сила движения RSI** (20%): чем быстрее движется к порогу, тем выше уверенность
   - **Близость к целевому уровню** (20%): чем ближе RSI к порогу, тем надежнее предсказание
   - **Стабильность скорости** (15%): стабильная скорость изменения повышает уверенность
   - **Горизонт предсказания** (10%): близкие события предсказываются точнее
   - **Согласованность движений** (10%): если RSI и цена движутся согласованно
   - **Экстремальные зоны** (15%): если RSI в экстремальной зоне (< 20 или > 80)

## Параметры конфигурации

```go
type RSIConfig struct {
    Period        int     // Период расчета RSI (обычно 14)
    BuyThreshold  float64 // Уровень перепроданности (обычно 30)
    SellThreshold float64 // Уровень перекупленности (обычно 70)
}
```

### Рекомендуемые значения

- **Классические параметры Уайлдера**: Period=14, BuyThreshold=30, SellThreshold=70
- **Более чувствительный вариант**: Period=9, BuyThreshold=25, SellThreshold=75
- **Более консервативный вариант**: Period=21, BuyThreshold=20, SellThreshold=80
- **Для скальпинга**: Period=7, BuyThreshold=20, SellThreshold=80

### Интерпретация уровней RSI

- **RSI > 70**: Зона перекупленности - возможен разворот вниз
- **RSI < 30**: Зона перепроданности - возможен разворот вверх
- **RSI > 80**: Экстремальная перекупленность - сильный сигнал разворота
- **RSI < 20**: Экстремальная перепроданность - сильный сигнал разворота
- **RSI ≈ 50**: Нейтральная зона - нет четкого сигнала

## Структура предсказания

```go
type FutureSignal struct {
    SignalType SignalType // BUY, SELL или HOLD
    Date       int64      // Unix timestamp ожидаемого сигнала
    Price      float64    // Ожидаемая цена в момент сигнала
    Confidence float64    // Уверенность в предсказании (0.0 - 1.0)
}
```

## Интерпретация уверенности

- **≥ 0.80**: Очень высокая уверенность - RSI быстро движется к порогу в экстремальной зоне
- **0.70 - 0.79**: Высокая уверенность - сильное и стабильное движение RSI
- **0.50 - 0.69**: Средняя уверенность - движение стабильное, но медленное
- **0.30 - 0.49**: Низкая уверенность - слабое движение или далеко от порога
- **< 0.30**: Предсказание не возвращается (слишком низкая уверенность)

## Примеры использования

### Базовый пример

```go
package main

import (
    "bt/internal"
    "bt/strategies/v2/oscillators"
    "fmt"
    "time"
)

func main() {
    // Загружаем данные
    candles := loadCandles("data.json")
    
    // Создаем генератор
    generator := oscillators.NewRSISignalGenerator()
    
    // Конфигурация
    config := &oscillators.RSIConfig{
        Period:        14,
        BuyThreshold:  30.0,
        SellThreshold: 70.0,
    }
    
    // Предсказываем сигнал
    signal := generator.PredictNextSignal(candles, config)
    
    if signal != nil {
        fmt.Printf("Тип: %v\n", signal.SignalType)
        fmt.Printf("Дата: %v\n", time.Unix(signal.Date, 0))
        fmt.Printf("Цена: %.4f\n", signal.Price)
        fmt.Printf("Уверенность: %.1f%%\n", signal.Confidence*100)
    }
}
```

### Использование через V2 API

```go
// Получаем стратегию из реестра
strategy, _ := internal.GetStrategyV2("rsi_oscillator_v2")

// Оптимизируем параметры
config := strategy.Optimize(candles, strategy)
```

## Когда предсказание невозможно

Метод `PredictNextSignal` возвращает `nil` в следующих случаях:

1. **Недостаточно данных**: меньше чем `Period * 2` свечей
2. **Отсутствие направленного движения**: RSI не имеет четкого тренда (velocity ≈ 0)
3. **Слабое движение**: скорость изменения RSI слишком мала (< 0.1)
4. **Неблагоприятное направление**:
   - RSI в зоне перепроданности и продолжает падать
   - RSI в зоне перекупленности и продолжает расти
5. **Далекий горизонт**: достижение порога ожидается позже чем через `Period * 2` свечей
6. **Низкая уверенность**: расчетная уверенность < 0.30

## Ограничения и предостережения

### Технические ограничения

1. **Линейная экстраполяция**: предсказание основано на линейной экстраполяции, что может быть неточно при резких изменениях
2. **Запаздывание**: RSI - запаздывающий индикатор, основанный на исторических данных
3. **Ложные сигналы в трендах**: в сильных трендах RSI может долго оставаться в экстремальных зонах

### Рыночные условия

- **Лучше работает**: в боковых/осциллирующих рынках
- **Хуже работает**: в сильных трендовых рынках
- **Не подходит**: для рынков с резкими гэпами, низколиквидных активов

### Особенности RSI

1. **Дивергенции**: расхождение между RSI и ценой может сигнализировать о развороте
2. **Ложные пробои**: RSI может кратковременно пересечь порог и вернуться
3. **Зависимость от периода**: короткий период = больше сигналов, но больше шума

### Рекомендации по использованию

1. **Комбинируйте с трендовыми индикаторами**: используйте MA или SuperTrend для фильтрации
2. **Учитывайте уверенность**: игнорируйте предсказания с низкой уверенностью
3. **Проверяйте дивергенции**: расхождение RSI и цены - важный сигнал
4. **Используйте стоп-лоссы**: всегда защищайте позиции
5. **Адаптируйте пороги**: для разных активов могут подходить разные уровни
6. **Учитывайте волатильность**: в высоковолатильных рынках используйте более широкие пороги

## Продвинутые техники

### 1. Дивергенции

**Бычья дивергенция**: цена делает новый минимум, а RSI - нет
- Сигнал возможного разворота вверх
- Повышает уверенность в BUY предсказании

**Медвежья дивергенция**: цена делает новый максимум, а RSI - нет
- Сигнал возможного разворота вниз
- Повышает уверенность в SELL предсказании

### 2. Множественные таймфреймы

Проверяйте RSI на разных таймфреймах:
- Краткосрочный (5-7): для точки входа
- Среднесрочный (14): основной сигнал
- Долгосрочный (21-28): подтверждение тренда

### 3. Комбинация с другими индикаторами

- **RSI + MA**: фильтрация по тренду
- **RSI + Volume**: подтверждение силы движения
- **RSI + Bollinger Bands**: определение волатильности
- **RSI + MACD**: двойное подтверждение импульса

## Заключение

Метод `PredictNextSignal` для стратегии RSI Oscillator предоставляет мощный инструмент для прогнозирования моментов перекупленности и перепроданности. RSI - один из самых надежных и проверенных временем индикаторов, и его предсказания имеют высокую точность при правильном использовании. При применении с учетом рыночных условий, комбинации с трендовыми индикаторами и анализе дивергенций, RSI может значительно улучшить результаты торговли.

## Полезные ресурсы

- Оригинальная книга Дж. Уэллса Уайлдера "New Concepts in Technical Trading Systems" (1978)
- Классические уровни: 30/70 (стандарт), 20/80 (консервативный), 40/60 (агрессивный)
- Период 14 выбран Уайлдером как оптимальный баланс между чувствительностью и надежностью
