# Awesome Oscillator Strategy V2 - Предсказание сигналов

## Обзор

Стратегия Awesome Oscillator V2 расширена методом `PredictNextSignal`, который предсказывает ближайший момент пересечения AO с нулевой линией.

## Как работает предсказание

### Основная идея

Awesome Oscillator (AO) — индикатор Билла Вильямса, измеряющий изменение рыночной энергии. Он рассчитывается как разница между двумя простыми скользящими средними медианной цены:

```
AO = SMA(MedianPrice, 5) - SMA(MedianPrice, 34)
MedianPrice = (High + Low) / 2
```

Сигналы генерируются при пересечении нулевой линии:
- **BUY**: AO пересекает ноль снизу вверх (переход от отрицательных к положительным значениям)
- **SELL**: AO пересекает ноль сверху вниз (переход от положительных к отрицательным значениям)

### Алгоритм предсказания

1. **Анализ текущего состояния**
   - Определяем текущее значение AO
   - Определяем положение относительно нуля (выше/ниже)
   - Вычисляем расстояние до нулевой линии

2. **Вычисление скорости изменения**
   - Скорость изменения AO (aoVelocity) - производная AO
   - Скорость изменения медианной цены (medianVelocity)
   - Анализируем последние 3-5 свечей для определения тренда

3. **Проверка возможности пересечения**
   - Если AO > 0 и растет → расхождение от нуля, предсказание невозможно
   - Если AO < 0 и падает → расхождение от нуля, предсказание невозможно
   - Только при движении к нулю возможно предсказание

4. **Расчет времени до пересечения**
   ```
   candlesToCrossing = |distanceToZero / aoVelocity|
   ```

5. **Экстраполяция в будущее**
   - Прогнозируем значение AO в момент пересечения (должно быть ≈ 0)
   - Прогнозируем медианную цену в этот момент
   - Используем медианную цену как предсказанную цену сигнала

6. **Оценка уверенности**
   Уверенность вычисляется на основе нескольких факторов:
   - **Сила движения AO** (20%): чем быстрее движется к нулю, тем выше уверенность
   - **Близость к нулю** (20%): чем ближе AO к нулю, тем надежнее предсказание
   - **Стабильность скорости** (15%): стабильная скорость изменения повышает уверенность
   - **Горизонт предсказания** (10%): близкие события предсказываются точнее
   - **Согласованность движений** (10%): если AO и медианная цена движутся согласованно

## Параметры конфигурации

```go
type AOConfig struct {
    FastPeriod          int  // Период быстрой SMA (обычно 5)
    SlowPeriod          int  // Период медленной SMA (обычно 34)
    ConfirmByTwoCandles bool // Подтверждение двумя свечами
}
```

### Рекомендуемые значения

- **Классические параметры Билла Вильямса**: FastPeriod=5, SlowPeriod=34
- **Более чувствительный вариант**: FastPeriod=3, SlowPeriod=21
- **Более стабильный вариант**: FastPeriod=7, SlowPeriod=55

### Подтверждение двумя свечами

Опция `ConfirmByTwoCandles` добавляет дополнительное условие:
- Для BUY: две последние медианные цены должны расти
- Для SELL: две последние медианные цены должны падать

Это снижает количество ложных сигналов, но может пропустить некоторые хорошие входы.

## Структура предсказания

```go
type FutureSignal struct {
    SignalType SignalType // BUY, SELL или HOLD
    Date       int64      // Unix timestamp ожидаемого сигнала
    Price      float64    // Ожидаемая медианная цена в момент сигнала
    Confidence float64    // Уверенность в предсказании (0.0 - 1.0)
}
```

## Интерпретация уверенности

- **≥ 0.70**: Высокая уверенность - AO быстро движется к нулю
- **0.50 - 0.69**: Средняя уверенность - движение стабильное, но медленное
- **0.30 - 0.49**: Низкая уверенность - слабое движение или далеко от нуля
- **< 0.30**: Предсказание не возвращается (слишком низкая уверенность)

## Примеры использования

### Базовый пример

```go
package main

import (
    "bt/internal"
    "bt/strategies/v2/oscillators"
    "fmt"
    "time"
)

func main() {
    // Загружаем данные
    candles := loadCandles("data.json")
    
    // Создаем генератор
    generator := oscillators.NewAOSignalGenerator()
    
    // Конфигурация
    config := &oscillators.AOConfig{
        FastPeriod:          5,
        SlowPeriod:          34,
        ConfirmByTwoCandles: false,
    }
    
    // Предсказываем сигнал
    signal := generator.PredictNextSignal(candles, config)
    
    if signal != nil {
        fmt.Printf("Тип: %v\n", signal.SignalType)
        fmt.Printf("Дата: %v\n", time.Unix(signal.Date, 0))
        fmt.Printf("Цена: %.4f\n", signal.Price)
        fmt.Printf("Уверенность: %.1f%%\n", signal.Confidence*100)
    }
}
```

### Использование через V2 API

```go
// Получаем стратегию из реестра
strategy, _ := internal.GetStrategyV2("awesome_oscillator_v2")

// Оптимизируем параметры
config := strategy.Optimize(candles, strategy)

// Генерируем сигналы
signals := strategy.GenerateSignals(candles, config)

// Предсказываем следующий сигнал
if strategyBase, ok := strategy.(*internal.StrategyBase); ok {
    futureSignal := strategyBase.PredictNextSignal(candles, config)

}
```

## Когда предсказание невозможно

Метод `PredictNextSignal` возвращает `nil` в следующих случаях:

1. **Недостаточно данных**: меньше чем `SlowPeriod * 2` свечей
2. **Расхождение от нуля**: 
   - AO > 0 и растет (движется от нуля вверх)
   - AO < 0 и падает (движется от нуля вниз)
3. **Слабое движение**: скорость изменения AO слишком мала (< 0.00001)
4. **Далекий горизонт**: пересечение ожидается позже чем через `SlowPeriod` свечей
5. **Низкая уверенность**: расчетная уверенность < 0.30

## Ограничения и предостережения

### Технические ограничения

1. **Линейная экстраполяция**: предсказание основано на линейной экстраполяции, что может быть неточно при резких изменениях
2. **Зависимость от импульса**: в периоды слабого импульса точность снижается
3. **Запаздывание**: AO - запаздывающий индикатор, основанный на SMA

### Рыночные условия

- **Лучше работает**: в трендовых рынках с четкими импульсами
- **Хуже работает**: в боковых рынках, при слабой волатильности
- **Не подходит**: для скальпинга, рынков с частыми ложными пробоями

### Особенности AO

1. **Медианная цена**: AO использует (High + Low) / 2, а не Close
2. **Пересечение нуля**: единственный критерий для сигналов
3. **Без уровней перекупленности/перепроданности**: в отличие от RSI или Stochastic

### Рекомендации по использованию

1. **Комбинируйте с трендовыми индикаторами**: используйте MA или SuperTrend для фильтрации
2. **Учитывайте уверенность**: игнорируйте предсказания с низкой уверенностью
3. **Проверяйте объем**: сильные сигналы AO должны подтверждаться объемом
4. **Используйте стоп-лоссы**: всегда защищайте позиции
5. **Тестируйте на истории**: проверяйте параметры на исторических данных

## Сравнение с другими осцилляторами

| Осциллятор | Основа расчета | Сложность предсказания | Точность | Запаздывание |
|------------|----------------|------------------------|----------|--------------|
| RSI | Относительная сила | Средняя | Средняя | Среднее |
| Stochastic | Положение в диапазоне | Средняя | Средняя | Низкое |
| CCI | Отклонение от средней | Средняя | Высокая | Среднее |
| **AO** | **Разница SMA** | **Низкая** | **Высокая** | **Высокое** |

Awesome Oscillator проще в предсказании, так как использует только одно условие (пересечение нуля), но имеет большее запаздывание из-за использования SMA.

## Преимущества и недостатки

### Преимущества

✅ Простая логика - только пересечение нуля
✅ Четкие сигналы без субъективности
✅ Хорошо работает в трендовых рынках
✅ Не требует настройки уровней
✅ Учитывает рыночную энергию

### Недостатки

❌ Запаздывает из-за использования SMA
❌ Много ложных сигналов в боковике
❌ Не показывает силу тренда
❌ Игнорирует цену закрытия
❌ Требует подтверждения другими индикаторами

## Дальнейшее развитие

Возможные улучшения:

1. **Дополнительные паттерны**: Twin Peaks, Saucer (классические паттерны AO)
2. **Адаптивные периоды**: автоматическая подстройка FastPeriod и SlowPeriod
3. **Фильтрация по объему**: учет объема для подтверждения сигналов
4. **Комбинация с Accelerator**: использование AC для раннего входа
5. **Машинное обучение**: обучение модели на исторических паттернах AO

## Заключение

Метод `PredictNextSignal` для стратегии Awesome Oscillator предоставляет простой и эффективный инструмент для прогнозирования разворотов импульса. Благодаря простоте расчета и четким критериям, предсказания AO легко интерпретировать и использовать в торговле. При правильном применении с учетом ограничений и в комбинации с трендовыми индикаторами, AO может значительно улучшить результаты торговли.
