# Ulcer Index Strategy V2 - Предсказание сигналов

## Описание стратегии

Ulcer Index (UI) — это индикатор, измеряющий downside risk (риск снижения). Индекс растет по мере того, как цена уходит все дальше от недавнего максимума, и падает по мере достижения новых максимумов. В отличие от стандартного отклонения, Ulcer Index фокусируется только на просадках, игнорируя восходящую волатильность.

### Формула

```
UI = √(Σ((Close - MaxHigh) / MaxHigh)² / period)
```

где:
- `Close` — цена закрытия текущей свечи
- `MaxHigh` — максимальная цена High за период
- `period` — период расчета (обычно 14)

### Интерпретация

- **UI низкий (< 2.8%)** — низкий риск снижения, цена близка к максимумам
- **UI средний (2.8-4.4%)** — умеренный риск, нормальные просадки
- **UI высокий (> 4.4%)** — высокий риск, значительные просадки от максимумов

**Примечание:** Для длинного периода (300 свечей) пороги значительно ниже, чем для короткого периода (14 свечей).

## Торговые правила

### Сигнал на покупку (BUY)
- Ulcer Index **падает ниже** порога покупки (buyThreshold)
- Означает, что риск снижается
- Цена восстанавливается к максимумам
- Хорошее время для входа в позицию

### Сигнал на продажу (SELL)
- Ulcer Index **растет выше** порога продажи (sellThreshold)
- Означает, что риск увеличивается
- Цена значительно отклонилась от максимумов
- Время выхода из позиции для защиты капитала

## Параметры стратегии

| Параметр | Описание | Значение по умолчанию | Диапазон оптимизации |
|----------|----------|----------------------|---------------------|
| `period` | Период для расчета UI | 300 | 300-400 (шаг 10) |
| `buy_threshold` | Порог для покупки (низкий риск) | 0.028 (2.8%) | 0.02-0.03 (шаг 0.002) |
| `sell_threshold` | Порог для продажи (высокий риск) | 0.044 (4.4%) | buy+0.01 до 0.07 (шаг 0.002) |

## Алгоритм предсказания

Метод `PredictNextSignal` анализирует текущее состояние индикатора и предсказывает следующий торговый сигнал.

### Этапы предсказания

1. **Расчет текущих значений**
   - Вычисляется Ulcer Index для всех свечей
   - Определяется текущее значение UI

2. **Анализ скорости изменения**
   - Вычисляется средняя скорость изменения UI за последние N свечей
   - Определяется направление движения индикатора

3. **Определение целевого уровня**
   - Если UI < buyThreshold и растет → ожидается SELL
   - Если UI > sellThreshold и падает → ожидается BUY
   - В нейтральной зоне учитывается направление движения

4. **Расчет времени до сигнала**
   ```
   candlesToTarget = |distanceToTarget| / |uiVelocity|
   ```

5. **Экстраполяция цены**
   - Вычисляется средняя скорость изменения цены
   - Прогнозируется цена в момент сигнала

6. **Оценка уверенности**
   - Анализируется множество факторов (см. ниже)

### Факторы уверенности

Уверенность в предсказании (confidence) рассчитывается на основе следующих факторов:

| Фактор | Влияние | Описание |
|--------|---------|----------|
| **Сила движения UI** | +0.10 до +0.20 | Чем быстрее изменяется UI, тем выше уверенность |
| **Близость к целевому уровню** | +0.10 до +0.20 | Чем ближе к порогу, тем скорее произойдет сигнал |
| **Стабильность скорости** | +0.10 до +0.15 | Постоянство скорости изменения на предыдущих периодах |
| **Горизонт предсказания** | -0.20 до +0.10 | Близкие предсказания надежнее дальних |
| **Тренд максимумов** | +0.05 до +0.15 | Согласованность движения UI с трендом максимумов |
| **Обратная корреляция с ценой** | -0.05 до +0.10 | UI обычно растет когда цена падает (и наоборот) |

**Минимальный порог уверенности:** 0.30 (30%)

### Условия отказа от предсказания

Предсказание не выполняется, если:
- Недостаточно исторических данных (< period × 2 свечей)
- UI движется в направлении от целевого уровня
- Слишком слабое движение индикатора (< 0.0001)
- Нет направленного движения (velocity ≈ 0)
- Уверенность ниже минимального порога (< 30%)

## Интерпретация результатов

### Высокая уверенность (> 60%)
- Сильное направленное движение UI
- Близость к целевому уровню
- Стабильная скорость изменения
- Согласованность с трендом максимумов

**Рекомендация:** Можно рассматривать для торговли

### Средняя уверенность (40-60%)
- Умеренное движение индикатора
- Средний горизонт предсказания
- Частичная согласованность факторов

**Рекомендация:** Требуется дополнительное подтверждение

### Низкая уверенность (30-40%)
- Слабое движение UI
- Нестабильность или дивергенция
- Дальний горизонт предсказания

**Рекомендация:** Высокий риск, лучше дождаться более четкого сигнала

## Преимущества и ограничения

### Преимущества
✅ Фокусируется на downside risk (риск снижения)  
✅ Игнорирует восходящую волатильность  
✅ Хорошо измеряет просадки от максимумов  
✅ Полезен для risk-adjusted returns  
✅ Помогает определить периоды повышенного риска  

### Ограничения
⚠️ Не является торговым индикатором сам по себе  
⚠️ Требует дополнительных фильтров  
⚠️ Запаздывает при быстрых движениях  
⚠️ Зависит от правильного выбора периода  
⚠️ Лучше работает в комбинации с другими индикаторами  

## Рекомендации по использованию

1. **Комбинируйте с трендовыми индикаторами**
   - Используйте MA для определения общего тренда
   - Добавьте SuperTrend для подтверждения направления
   - Проверяйте на более длинных таймфреймах

2. **Оптимизируйте параметры**
   - Для краткосрочной торговли: используйте меньший period (50-100)
   - Для долгосрочной торговли: используйте больший period (300-400)
   - Настройте пороги под волатильность актива
   - Помните: чем больше period, тем ниже должны быть пороги

3. **Учитывайте рыночные условия**
   - В трендовом рынке: UI помогает определить точки входа
   - В боковом рынке: используйте более широкие пороги
   - При высокой волатильности: увеличьте sellThreshold

4. **Управление рисками**
   - Используйте UI для sizing позиций
   - Не входите при высоком UI (> sellThreshold)
   - Учитывайте уверенность предсказания
   - Комбинируйте с stop-loss

### Минимальные требования к данным

## Особенности реализации

### Расчет Ulcer Index
```go
// Для каждого окна:
1. Находим максимум High за период
2. Для каждой свечи: drawdown = (Close - MaxHigh) / MaxHigh
3. Возводим drawdown в квадрат
4. Берем среднее квадратов
5. Извлекаем квадратный корень
```

### Анализ тренда максимумов
Предсказание учитывает, растут или падают максимумы:
- Растущие максимумы + падающий UI = хороший знак для BUY
- Падающие максимумы + растущий UI = хороший знак для SELL

### Обратная корреляция
UI обычно движется в направлении, обратном цене:
- Цена растет → UI падает (новые максимумы)
- Цена падает → UI растет (просадка от максимумов)

## Практические примеры

### Пример 1: Вход после коррекции (period=300)
```
UI падает с 3.5% до 2.5% → BUY сигнал
Интерпретация: Коррекция завершена, риск снизился
```

### Пример 2: Выход при росте риска (period=300)
```
UI растет с 2.8% до 4.5% → SELL сигнал
Интерпретация: Начинается просадка, риск увеличивается
```

### Пример 3: Комбинация с трендом (period=300)
```
Восходящий тренд + UI < 2.8% → Сильный BUY
Нисходящий тренд + UI > 4.4% → Сильный SELL
```
