# Elliott Wave Advanced V2 - Расширенная волновая теория Эллиота

## Описание

Полноценная реализация волновой теории Эллиота с расширенным функционалом и предиктивными сигналами. Это улучшенная версия базовой стратегии `elliott_wave_v2`, которая включает все основные правила и принципы волнового анализа.

## Ключевые особенности

### 1. Полная идентификация волн
- **5 импульсных волн**: 1, 2, 3, 4, 5
- **3 коррекционных волны**: A, B, C
- Автоматическое определение типа каждой волны
- Альтернативные подсчеты для неоднозначных ситуаций

### 2. Правила Эллиота
Стратегия строго следует классическим правилам:
- ✅ Волна 2 никогда не пересекает начало волны 1
- ✅ Волна 3 не может быть самой короткой из импульсных волн
- ✅ Волна 3 обычно самая длинная (минимум в 1.5 раза больше волны 1)
- ✅ Волна 4 не заходит на территорию волны 1
- ✅ Правило чередования: коррекции 2 и 4 должны быть разными

### 3. Уровни Фибоначчи
Использует множественные уровни Фибоначчи для точной идентификации:
- **Откаты**: 0.236, 0.382, 0.5, 0.618, 0.786
- **Расширения**: 1.0, 1.272, 1.618, 2.618
- Автоматическая проверка соответствия волн уровням Фибоначчи
- Увеличение уверенности при совпадении с классическими уровнями

### 4. Паттерны коррекции
Идентифицирует различные типы коррекционных паттернов:
- **Зигзаг (5-3-5)**: резкая коррекция
- **Плоскость (3-3-5)**: боковая коррекция
- **Треугольник (3-3-3-3-3)**: сужающаяся коррекция
- **Сложная коррекция**: комбинированные паттерны

### 5. Временные соотношения
Анализирует временные пропорции между волнами:
- Соотношения длительности волн
- Проверка на соответствие Фибоначчи во времени
- Предсказание времени завершения волны

### 6. Система уверенности
Каждая волна имеет коэффициент уверенности (0-1):
- Базовая уверенность: 0.5
- +0.2 за соответствие правилам импульса/коррекции
- +0.1 за соответствие уровням Фибоначчи
- +0.05 за временные соотношения
- Сигналы генерируются только при уверенности выше порога

## Параметры конфигурации

```json
{
  "min_wave_length": 5,              // минимальная длина волны в свечах
  "max_wave_length": 50,             // максимальная длина волны
  "min_wave_amplitude": 0.01,        // минимальная амплитуда волны (1%)
  "fib_retracement_min": 0.382,      // минимальный откат Фибоначчи
  "fib_retracement_max": 0.618,      // максимальный откат Фибоначчи
  "fib_extension_min": 1.0,          // минимальное расширение Фибоначчи
  "fib_extension_max": 1.618,        // максимальное расширение Фибоначчи
  "wave3_min_multiplier": 1.5,       // волна 3 минимум в 1.5 раза больше волны 1
  "wave5_max_multiplier": 1.0,       // волна 5 максимум равна волне 1
  "trend_strength": 0.3,             // минимальная сила тренда
  "use_alternative_counts": true,    // использовать альтернативные подсчеты
  "use_time_relations": true,        // анализировать временные соотношения
  "use_correction_patterns": true,   // идентифицировать паттерны коррекции
  "confidence_threshold": 0.5        // порог уверенности для сигнала
}
```

## Логика генерации сигналов

### Сигналы BUY
1. **После волны 2**: начало мощной волны 3
   - Цена откатила на 38.2-61.8% от волны 1
   - Начинается разворот вверх
   - **Высокая уверенность**: 0.9

2. **После волны 4**: начало финальной волны 5
   - Цена откатила на 38.2% от волны 3
   - Не зашла на территорию волны 1
   - **Средняя уверенность**: 0.8

3. **После волны C**: начало нового импульсного цикла
   - Коррекция завершена
   - Начинается новая волна 1
   - **Средняя уверенность**: 0.75

### Сигналы SELL
1. **После волны 5**: завершение импульса
   - Все 5 волн идентифицированы
   - Ожидается коррекция A-B-C
   - **Высокая уверенность**: 0.85

2. **После волны 3**: коррекция волной 4
   - Волна 3 завершена
   - Временная коррекция
   - **Средняя уверенность**: 0.75

3. **После волны B**: финальное падение волной C
   - Откат завершен
   - Ожидается волна C
   - **Средняя уверенность**: 0.7

## Предиктивные возможности

Стратегия полностью предиктивна и предсказывает:
- **Тип следующей волны**: на основе текущей волновой структуры
- **Целевую цену**: используя уровни Фибоначчи и длины предыдущих волн
- **Время достижения**: на основе средней длительности волн
- **Уверенность**: вероятность правильности предсказания

### Пример предсказания

```
Предсказание: Wave 3 (импульс)

Целевая цена: +16.18% от текущей (расширение 1.618)
Время: через 15 свечей
Уверенность: 90%
```

## Преимущества

1. **Точность**: строгое следование правилам Эллиота
2. **Гибкость**: множество параметров для настройки
3. **Предсказуемость**: полностью предиктивные сигналы
4. **Надежность**: система уверенности фильтрует слабые сигналы
5. **Универсальность**: работает на разных таймфреймах и активах

## Недостатки

1. **Сложность**: требует больше вычислительных ресурсов
2. **Время оптимизации**: grid search может занять много времени
3. **Субъективность**: волновой анализ имеет элемент интерпретации
4. **Ложные сигналы**: в боковых рынках может давать ошибочные сигналы
